# アメ何個いる？（ポケモンスリープ アメ・経験値シミュレータ）

ポケモンスリープで、目標のレベルまでに必要な
**アメの数・ゆめのかけら・経験値（EXP）** を計算するサイトです。

もとになったサイト（更新が止まっているもの）
<https://kerusu-1984.github.io/pokemon-sleep-calc-required-candy/>
とほぼ同じ見た目・使い勝手のまま、

- **Ver.3.6.0（2026年6月25日）のレベル上限70** に対応
- **今の経験値テーブル**（アメ1個の経験値が Lv.24まで40／Lv.25〜29は35／Lv.30以上は25）に対応
- 経験値タイプに **1320タイプ（ミュウ・ダークライ）** を追加
- **「鶴亀算」機能**（持っているアメをちょうど使い切る配分を計算）を追加
- **「つぎのレベルまで あと ◯◯」の入力欄**を追加（ゲームの表示をそのまま入れて差し引き計算）
- **アメが足りないときの補い方**（手持ちのばんのうアメ・タイプのアメから、いちばんキリのいい組み合わせを提案）を追加
- **「アメブーストできるアメの数（残り）」の入力欄**を追加（残りのブースト枠のぶんだけを使う前提で計算）
- **「お昼寝島」の欄**を追加（島で稼いだEXPと拾ったアメを差し引いて、目標レベルまでの残りEXPを出す）

したものです。

## 2. 使い方（自分のパソコンで開く）

1. エクスプローラー（フォルダを開くアプリ）を開きます。
2. 左側または上のアドレス欄から `PC` → `ローカルディスク (C:)` → `ユーザー`
   → `oauao` → `Claude` → `ポケスリ` → `pokemon-candy-calc` と順番に開きます。
3. その中の **`サイトを開く.bat`** をダブルクリックします。
4. ブラウザ（Edge や Chrome）が立ち上がり、サイトが表示されれば成功です。

> `index.html` を直接ダブルクリックしても同じように開きます。
> どちらでも構いません。

## 3. 画面の見かた

### 上半分（もとのサイトと同じ部分）

- **現在のレベル / 目標のレベル**
  「－」「＋」ボタンか、下のスライダーで変えられます。**1〜70** まで選べます。
- **あと ◯◯（つぎのレベルまでの残り経験値）**
  現在のレベルのスライダーの下にある入力欄です。
  ゲームの画面に出ている **「つぎのレベルまで あと ◯◯」の数字をそのまま**入れてください。
  そのぶんを差し引いて計算します。
  - 右の「/ ◯◯」は、**次のレベルになるまでの必要経験値**（満タンの数）です
  - それ以上の数字は入れられません（自動で上限に丸められます）
  - まだ何もたまっていない（レベルが上がった直後）なら、右と同じ数字が入ります
  - レベルや経験値タイプを変えると、上限も自動で切り替わります
  - 数字だけ入る欄なので、スマホでは数字キーボードが出ます
  - レベル70のときは入力できません（次のレベルがないため）
- **経験値タイプ**
  ポケモンによって必要な経験値がちがいます。「?」を押すと説明が出ます。
  - `600` … ほとんどのポケモン
  - `900` … ミニリュウ系統、ヨーギラス系統、タツベイ系統
  - `1080` … ライコウ、エンテイ、スイクン、クレセリア、ラティアス、ラティオス
  - `1320` … ミュウ、ダークライ
- **性格による経験値補正**
  - `▲` … EXPが増えやすい性格（1.18倍）
  - `-` … 補正なし
  - `▼` … EXPが増えにくい性格（0.82倍）
- **アメブースト**
  スイッチをONにすると「アメブースト（ゆめのかけら5倍）」の計算になります。
  さらに左の「ミニ」にチェックを入れると「ミニアメブースト（ゆめのかけら4倍）」になります。

その下に、**必要なアメの数／ゆめのかけら／目標レベルまでの必要EXP** が表示されます。

### 下半分（新しく追加した「鶴亀算」）

「持っているアメの数」を入れると、

- **アメブーストで何個** 使って
- **通常で何個** 使えば

**持っているアメをちょうど使い切って**目標レベルに届くかを計算します。

あわせて、

- 全部ふつうに使った場合
- アメブーストを使えるだけ使った場合
- その中間（鶴亀算の答え）

の3つを表で見くらべられます。
答えの下には、**そのときに必要なゆめのかけら**も出ます。

表のいちばん右「持っているアメで足りる？」の欄は、足りていれば `OK`、
足りていなければ **`× あと◯個`** と、**不足しているアメの数**まで出ます。

### アメブーストできるアメの数（残り）

「使うアメブーストの種類」のすぐ下にある入力欄です。
**アメブーストで使えるアメが、あと何個ぶん残っているか**を入れます。
ここに入れた数までしかアメブーストを使わないものとして計算します。

- ゲームの1日の上限は **ミニアメブースト＝50個／アメブースト＝500個** です
- 種類（ミニ／通常）を切りかえると、その種類の上限（50／500）に自動で戻ります
- 残りぶんを使い切っても届かないときは
  **「アメブーストを ◯ 個ぶん使い切っても、Lv.◯ まであと ◯ 個」** と出ます

> **例**
> Lv.40 → Lv.60（600タイプ・補正なし）だと、ふつうに使うと 1,256個 必要です。
> アメを 1,100個 持っていて、ブーストの残りが 100個ぶんなら
> → ブーストを100個使っても 1,156個 いるので、**あと56個足りない**、と分かります。

> **なぜ「先にアメブースト → あとから通常」なのか**
> アメ1個あたりのゆめのかけらは、レベルが低いほど安いです。
> なので、**安いうち（レベルが低いうち）にアメブーストを使い切る**のがいちばん得になります。
> このツールもその順番で計算しています。

### アメが足りないときの「補い方」

アメが足りないとき、答えの下に **`足りない ◯ 個 の補い方を見る ▼`** というボタンが出ます。
**押すと中身が開きます**（ふだんはたたまれているので、画面が長くなりません）。
もう一度押すと閉じます。数字を入れなおしても、開いたままなら開いたままです。

開いた中に **「持っているアイテム」の入力欄**があります。
**ばんのうアメ S/M/L**、**タイプのアメ S/M** の手持ち数を入れると、
**手持ちの中でいちばんキリよく補える組み合わせ** がすぐ下に出ます。

- アメが足りているときは、ボタンごと出ません（使わない欄なので隠れます）
- 入れた数字は、閉じても消えません

- **おすすめ**の1行 … ばんのうアメLをいちばん使わずに済む組み合わせ
- **比較表** … Lを1個ずつ増やしたときに、小さいアメがどれだけ減るか

> **考え方**
> 大きいアメ（特にばんのうアメL）は貴重なので、**なるべく小さいアメで埋める**ようにしています。
> そのうえで、**むだ（作りすぎ）がいちばん少なくなる**組み合わせを選びます。
> 例：足りないアメ467個／ばんのうアメ S100個・L5個 を持っている場合
> → **L 2個 ＋ S 89個（ちょうど467個ぶん・むだなし）** がおすすめになります。
> L を3個・4個と増やすと S は減りますが、そのぶんむだが出ます。

アイテムを1つも入力していないときは、
**「1種類だけで補う場合」の早見表**が代わりに表示されます。

交換レート（ポケモンのアメ何個ぶんになるか）

| アイテム | アメ何個ぶん |
|---|---|
| ばんのうアメ S | 3個 |
| ばんのうアメ M | 20個 |
| ばんのうアメ L | 100個 |
| タイプのアメ S | 4個 |
| タイプのアメ M | 25個 |

※タイプのアメに L はありません。
※どちらも、**ボックスにいるポケモンのアメにしか変換できません**。

## 3-2. お昼寝島の欄

ページのいちばん下にある「**お昼寝島：目標レベルまであと何EXP？**」の欄です。
上で選んだ「現在のレベル・目標のレベル・経験値タイプ・性格補正・あと◯◯」をそのまま使います。

画面まん中に出ている「**目標のレベルまであと EXP ◯◯**」を出発点にして、
そこから順番に引き算していきます。

> **注意：7日間預ける想定の計算です**
> それ以前に引き取ると、**経験値が半減**になります。
> このツールは半減を計算に入れていないので、早めに引き取る場合は
> 出てくるEXPより実際は少なくなる、と思ってお使いください。

### 入れるところ

1. **島のポケモンに出ているEXP**
   お昼寝島にいるポケモンに表示されている経験値を、そのまま入れます。
2. **ものひろい箱のアメ**
   アメは1回で **1個・3個・5個** のどれかが手に入るので、
   拾うたびに **`＋1` `＋3` `＋5`** のボタンを押していきます。
   - 押すたびに **合計** と **押した回数**、拾った順番が下に出ます
   - 押し間違えたら **`ひとつ戻す`**、最初からやり直すなら **`全部消す`**
3. **ほかに持っているアメ**
   ボックスに元から持っているぶんがあれば、その個数を入れます。
   （下の鶴亀算の「持っているアメ」とは別の欄です。連動していません）
4. **アメブースト（EXP2倍）**
   ONにすると、上のアメを**アメブーストで使う**ものとして計算します。
   このスイッチは、この欄だけに効きます。ページ上のほうのアメブーストとは別ものです。
5. **島で1日にもらえるEXP**
   **`ふつう（150）`** か **`チケット（600）`** を選びます。
   リラックスチケットを使っているときは「チケット」を選んでください。

### 出るもの

**目標レベルまで 残り ◯◯ EXP** が大きく出ます。
届く場合は「**Lv.◯◯ に届きます！**」と出て、あまったアメの数も出ます。

そのすぐ下に、**あと何時間 島に置いておけば届くか**が出ます。

- **あと ◯日◯時間◯分**
- **いま預けたままなら、◯月◯日 ◯◯:◯◯ ごろに引き取ると Lv.◯◯ です**（引き取る時刻の目安）

日付と時刻は、**見ている端末（スマホやパソコン）の時計**から計算しています。
ページを開きっぱなしにしていてもズレないよう、**1分ごとに出し直し**ています。

さらにその下に、引き算の内訳が表で出ます。

| 行 | 意味 |
|---|---|
| 目標レベルまでの残りEXP | 出発点（画面まん中の数と同じ） |
| － 島のポケモンに出ているEXP | 島で稼いだぶん |
| － アメ ◯個ぶん | アメを使ってもらえるEXP |
| 目標レベルまで 残り | 最後に残るEXP |

> **島でもらえるEXPの計算式**
> もらえるEXP ＝ **1日のEXP × 性格補正 × 預けた分数 ÷ 1440**（小数点以下は切り捨て）
> なので、必要な分数は「**残りEXP × 1440 ÷（1日のEXP × 性格補正）**」の切り上げです。
> ここでの**性格補正は ▲ だけ 1.18 倍**で、「-」と「▼」はどちらも **1 倍**です。
> **お昼寝島では▼（マイナス補正）は効かない**ため、わざと計算に入れていません。
> アメの計算（▼は0.82倍）とはちがうので、別に持たせています。
> ▼を選んでいるときは、画面にも「▼の補正は島では効かないので入れていません」と出ます。

> **アメのEXPは「かけ算」ではありません**
> アメ1個でもらえる経験値は、そのときのレベルで変わります（Lv.24まで40／Lv.25〜29は35／Lv.30以上は25）。
> アメを使っている途中でレベルが上がると単価も変わるので、
> **1個ずつ順番に使ったものとして計算**しています。性格補正もそのまま効きます。

## 4. 数値のもとになったデータ

- ポケモンスリープ攻略・検証 Wiki* 「育成/レベル」
- 同「育成/経験値タイプ」
- 同「アメブースト」
- 同「どうぐ/ばんのうアメ」「どうぐ/タイプのアメ」

いずれも 2026年8月時点（Ver.3.6.0 以降）の数値です。

**計算の考え方**

- 目標レベルまでの必要EXP＝ 累計EXP(目標) − 累計EXP(現在) − そのレベルでたまっているEXP
  （「あと ◯◯」の欄は、内部で「たまっているEXP＝必要EXP − あと ◯◯」に直しています）
- アメ1個の経験値は、**そのときのポケモンのレベル**で決まります
  （Lv.24まで＝40 / Lv.25〜29＝35 / Lv.30以上＝25。性格補正はこの値にかかります）
- 余った経験値は次のレベルに持ち越されます（ゲーム内と同じ）
- ゆめのかけらは「アメを使ったときのレベル」の値段 × 使った個数
- アメブースト中は、経験値2倍・ゆめのかけら5倍（ミニは4倍）

## 5. ゲームのアップデートで数値が変わったときの直し方

`index.html` をメモ帳で開いて、下のほうにある **`<script>`** の中の
次の3か所を直せば対応できます。

| 直す場所 | 内容 |
|---|---|
| `var TOTAL_EXPS = [ ... ];` | 各レベルの**累計必要経験値**（600タイプ）。先頭がLv.1、最後がLv.70 |
| `var SHARDS = [ ... ];` | **アメ1個あたりのゆめのかけら**。`SHARDS[レベル]` の形 |
| `var CANDY_EXP = { ... };` | **アメ1個の経験値**。`[Lv.24まで, Lv.25〜29, Lv.30以上]` の順 |
| `var ITEM_RATE = { ... };` | **ばんのうアメ・タイプのアメの交換レート** |

レベル上限が上がったときは、`var MAX_LEVEL = 70;` の数字も直してください。
