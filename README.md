# アメ何個いる？（ポケモンスリープ アメ・経験値シミュレータ）

ポケモンスリープで、目標のレベルまでに必要な
**アメの数・ゆめのかけら・経験値（EXP）** を計算するサイトです。

もとになったサイト（更新が止まっているもの）
<https://kerusu-1984.github.io/pokemon-sleep-calc-required-candy/>
とほぼ同じ見た目・使い勝手のまま、

- **Ver.3.6.0（2026年6月25日）のレベル上限70** に対応
- **今の経験値テーブル**（アメ1個の経験値が Lv.24まで40／Lv.25〜29は35／Lv.30以上は25）に対応
- 経験値タイプに **1320タイプ（ミュウ・ダークライ）** を追加
- **「鶴亀算」機能**（持っているアメをちょうど使い切る配分を計算）を追加
- **現在の経験値の入力欄**を追加（たまっているEXPを差し引いて計算）
- **アメが足りないときの補い方**（手持ちのばんのうアメ・タイプのアメから、いちばんキリのいい組み合わせを提案）を追加
- **「アメブーストできるアメの数（残り）」の入力欄**を追加（残りのブースト枠のぶんだけを使う前提で計算）

したものです。

## 2. 使い方（自分のパソコンで開く）

1. エクスプローラー（フォルダを開くアプリ）を開きます。
2. 左側または上のアドレス欄から `PC` → `ローカルディスク (C:)` → `ユーザー`
   → `oauao` → `Claude` → `ポケスリ` → `pokemon-candy-calc` と順番に開きます。
3. その中の **`サイトを開く.bat`** をダブルクリックします。
4. ブラウザ（Edge や Chrome）が立ち上がり、サイトが表示されれば成功です。

## 3. 画面の見かた

### 上半分（もとのサイトと同じ部分）

- **現在のレベル / 目標のレベル**
  「－」「＋」ボタンか、下のスライダーで変えられます。**1〜70** まで選べます。
- **現在の経験値（EXP）**
  現在のレベルのスライダーの下にある入力欄です。
  そのレベルで**すでにたまっている経験値**を入れると、そのぶん差し引いて計算します。
  - 右の「/ ◯◯」は、**次のレベルになるまでの必要経験値**です
  - それ以上の数字は入れられません（自動で上限に丸められます）
  - レベルや経験値タイプを変えると、上限も自動で切り替わります
  - 数字だけ入る欄なので、スマホでは数字キーボードが出ます
  - レベル70のときは入力できません（次のレベルがないため）
- **経験値タイプ**
  ポケモンによって必要な経験値がちがいます。「?」を押すと説明が出ます。
  - `600` … ほとんどのポケモン
  - `900` … ミニリュウ系統、ヨーギラス系統、タツベイ系統
  - `1080` … ライコウ、エンテイ、スイクン、クレセリア、ラティアス、ラティオス
  - `1320` … ミュウ、ダークライ
- **性格による経験値補正**
  - `▲` … EXPが増えやすい性格（1.18倍）
  - `-` … 補正なし
  - `▼` … EXPが増えにくい性格（0.82倍）
- **アメブースト**
  スイッチをONにすると「アメブースト（ゆめのかけら5倍）」の計算になります。
  さらに左の「ミニ」にチェックを入れると「ミニアメブースト（ゆめのかけら4倍）」になります。

その下に、**必要なアメの数／ゆめのかけら／目標レベルまでの必要EXP** が表示されます。

### 下半分（新しく追加した「鶴亀算」）

「持っているアメの数」を入れると、

- **アメブーストで何個** 使って
- **通常で何個** 使えば

**持っているアメをちょうど使い切って**目標レベルに届くかを計算します。

あわせて、

- 全部ふつうに使った場合
- アメブーストを使えるだけ使った場合
- その中間（鶴亀算の答え）

の3つを表で見くらべられます。
答えの下には、**そのときに必要なゆめのかけら**も出ます。

表のいちばん右「持っているアメで足りる？」の欄は、足りていれば `OK`、
足りていなければ **`× あと◯個`** と、**不足しているアメの数**まで出ます。

### アメブーストできるアメの数（残り）

「使うアメブーストの種類」のすぐ下にある入力欄です。
**アメブーストで使えるアメが、あと何個ぶん残っているか**を入れます。
ここに入れた数までしかアメブーストを使わないものとして計算します。

- ゲームの1日の上限は **ミニアメブースト＝50個／アメブースト＝500個** です
- 種類（ミニ／通常）を切りかえると、その種類の上限（50／500）に自動で戻ります
- 残りぶんを使い切っても届かないときは
  **「アメブーストを ◯ 個ぶん使い切っても、Lv.◯ まであと ◯ 個」** と出ます

> **例**
> Lv.40 → Lv.60（600タイプ・補正なし）だと、ふつうに使うと 1,256個 必要です。
> アメを 1,100個 持っていて、ブーストの残りが 100個ぶんなら
> → ブーストを100個使っても 1,156個 いるので、**あと56個足りない**、と分かります。

> **なぜ「先にアメブースト → あとから通常」なのか**
> アメ1個あたりのゆめのかけらは、レベルが低いほど安いです。
> なので、**安いうち（レベルが低いうち）にアメブーストを使い切る**のがいちばん得になります。
> このツールもその順番で計算しています。

### アメが足りないときの「補い方」

「持っているアイテム」に、**ばんのうアメ S/M/L**、**タイプのアメ S/M** の手持ち数を入れておくと、
アメが足りないときに **手持ちの中でいちばんキリよく補える組み合わせ** が自動で出ます。

- **おすすめ**の1行 … ばんのうアメLをいちばん使わずに済む組み合わせ
- **比較表** … Lを1個ずつ増やしたときに、小さいアメがどれだけ減るか

> **考え方**
> 大きいアメ（特にばんのうアメL）は貴重なので、**なるべく小さいアメで埋める**ようにしています。
> そのうえで、**むだ（作りすぎ）がいちばん少なくなる**組み合わせを選びます。
> 例：足りないアメ467個／ばんのうアメ S100個・L5個 を持っている場合
> → **L 2個 ＋ S 89個（ちょうど467個ぶん・むだなし）** がおすすめになります。
> L を3個・4個と増やすと S は減りますが、そのぶんむだが出ます。

アイテムを1つも入力していないときは、
**「1種類だけで補う場合」の早見表**が代わりに表示されます。

交換レート（ポケモンのアメ何個ぶんになるか）

| アイテム | アメ何個ぶん |
|---|---|
| ばんのうアメ S | 3個 |
| ばんのうアメ M | 20個 |
| ばんのうアメ L | 100個 |
| タイプのアメ S | 4個 |
| タイプのアメ M | 25個 |

※タイプのアメに L はありません。
※どちらも、**ボックスにいるポケモンのアメにしか変換できません**。

## 4. 数値のもとになったデータ

- ポケモンスリープ攻略・検証 Wiki* 「育成/レベル」
- 同「育成/経験値タイプ」
- 同「アメブースト」
- 同「どうぐ/ばんのうアメ」「どうぐ/タイプのアメ」

いずれも 2026年8月時点（Ver.3.6.0 以降）の数値です。

**計算の考え方**

- 目標レベルまでの必要EXP＝ 累計EXP(目標) − 累計EXP(現在) − 現在たまっているEXP
- アメ1個の経験値は、**そのときのポケモンのレベル**で決まります
  （Lv.24まで＝40 / Lv.25〜29＝35 / Lv.30以上＝25。性格補正はこの値にかかります）
- 余った経験値は次のレベルに持ち越されます（ゲーム内と同じ）
- ゆめのかけらは「アメを使ったときのレベル」の値段 × 使った個数
- アメブースト中は、経験値2倍・ゆめのかけら5倍（ミニは4倍）

## 5. ゲームのアップデートで数値が変わったときの直し方

`index.html` をメモ帳で開いて、下のほうにある **`<script>`** の中の
次の3か所を直せば対応できます。

| 直す場所 | 内容 |
|---|---|
| `var TOTAL_EXPS = [ ... ];` | 各レベルの**累計必要経験値**（600タイプ）。先頭がLv.1、最後がLv.70 |
| `var SHARDS = [ ... ];` | **アメ1個あたりのゆめのかけら**。`SHARDS[レベル]` の形 |
| `var CANDY_EXP = { ... };` | **アメ1個の経験値**。`[Lv.24まで, Lv.25〜29, Lv.30以上]` の順 |
| `var ITEM_RATE = { ... };` | **ばんのうアメ・タイプのアメの交換レート** |

レベル上限が上がったときは、`var MAX_LEVEL = 70;` の数字も直してください。
